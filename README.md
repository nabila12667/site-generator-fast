A faster drop-in for make.fun's own makefun-site 1.0.0: `solve.js` answers every case exactly as makefun-site 1.0.0 does — same output tree, byte for byte — with a leaner implementation: a single-pass Markdown renderer, bulk HTML escaping, an ASCII fast path for slugs, and no token arrays or per-character regex calls. `main.ts` is the program the harness runs: it reads every case from `/input/cases.json`, answers each with `run`, and writes `/output/answers.json`.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
